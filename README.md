This repo collects the SHAREing performance assessment of the Grid simulation library and the scripts used to generate the data for the report. The benchmarks were run on the `Sunbird` (since decommissioned) and `Sunbird2` clusters, hosted by Swansea University.

Important documents:
 - [SHAREing Performance Assessment Guidebook](https://github.com/SHAREing-DRI/Performance-Assessment-Guidebook)
 - [Grid](https://github.com/paboyle/Grid)
 - [Grid Benchmarks](https://github.com/gray95/grid-benchmark/tree/sunbird)

The assessment is made up of:
  - Pre-Assessment
  - High Level Assessment: CPU
  - High Level Assessment: GPU
